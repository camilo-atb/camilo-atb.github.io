# Portafolio Personal

Portafolio profesional desarrollado con **Angular 21**, **TypeScript** y **Tailwind CSS**. Presenta mi perfil, experiencia laboral, tecnologías, certificaciones y logros. Diseñado para que reclutadores, empresas y colegas conozcan mi trabajo de forma clara y directa.

## Tecnologías utilizadas

- Angular 21
- TypeScript
- Tailwind CSS v4
- SSR con Angular SSR

## Características

- Modo claro / oscuro
- 3 temas de color (azul, morado, verde)
- Internacionalización (español / inglés)
- Carrusel infinito de tecnologías
- Animaciones de scroll reveal
- Diseño responsive
- Preferencias persistidas en localStorage
- Página 100% estática (sin backend)

## Desarrollo local

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

Los archivos estáticos se generan en `dist/portfolio/browser/`.
